# رهیاب | نمونه اولیه وب

این شاخه محیط آزمایشی توسعه رابط وب رهیاب است. هیچ اتصال یا تغییری روی VPS و پایگاه داده عملیاتی انجام نمی‌دهد.

## فایل‌ها
- `index.html`: صفحه معرفی فارسی و راست‌چین
- `styles.css`: طراحی واکنش‌گرا برای موبایل و دسکتاپ
- `.devcontainer/devcontainer.json`: پیکربندی اولیه GitHub Codespaces
- `.gitignore`: قواعد پایه فایل‌های موقت و محرمانه

## اجرای محلی در Codespaces
پس از ساخت Codespace از همین شاخه، ترمینال را باز کنید و اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس از بخش Ports، پورت 8000 را باز کنید تا پیش‌نمایش صفحه نمایش داده شود.

## نکات
- این پروژه در مرحله نمونه اولیه است.
- فعلاً از داده واقعی املاک، نام مالکان، اسناد ثبتی یا اطلاعات محرمانه استفاده نکنید.
- پیش از افزودن هرگونه کلید یا رمز، آن را در فایل `.env` نگه دارید و هرگز در Git ثبت نکنید.
- Codespaces ممکن است هزینه مصرف منابع داشته باشد؛ پس از پایان کار آن را متوقف کنید.
